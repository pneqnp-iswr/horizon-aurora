# Horizon Aurora

Premium native visual enhancement suite for Horizon Minecraft, focused on polished HUD visuals, theme customization and reliable performance.

## Current vertical slice

- Native hook wiring (`hud`, `key`, `mods`, `settings`, `settings_click`)
- Animated PvP readability HUD card (CPS + combo telemetry)
- Five selectable visual themes with reduced-motion toggle
- Persistent JSON config model and unit-tested runtime core

See `docs/` for research, capability matrix, architecture, roadmap and testing notes.
